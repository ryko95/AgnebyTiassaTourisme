# Agnéby-Tiassa Tourisme — Android

Application Android officielle destinée à ouvrir le portail https://agnebytiassatourisme.com/ dans une interface mobile dédiée.

Fonctionnalités principales :
- écran de démarrage avec le logo du Conseil régional ;
- thème vert clair et orange ;
- accès rapide à l’accueil, aux sites touristiques, à la carte, aux expériences et au contact ;
- partage, rechargement et gestion des liens externes ;
- compilation automatique de l’APK avec GitHub Actions.

Projet préparé pour le Conseil régional de l’Agnéby-Tiassa.
